# Development Evidence Summary

This file summarises the evidence of planning, design, and AI-assisted development.

## Contents

| File | Purpose |
|---|---|
| `planning-design.md` | Records the original project planning and design decisions. |
| `ai-prompts.md` | Records the actual prompts used during AI-assisted development. |
| `agent-instructions.md` | Records the instructions and expectations used when working with an AI assistant. |
| `context-config.md` | Records project context and configuration notes used to guide development. |

## Planning Evidence

Planning evidence is shown through:

- The original full-stack plan with frontend, backend, and database layers
- Planned login, leaderboard, tutorial, game page, and homepage features
- A clear reason for each main feature
- Early decisions about where data and logic should belong

## Design Evidence

Design evidence is shown through:

- Homepage UI planning
- Tutorial flow planning
- Leaderboard layout planning
- Mobile usability considerations
- The difference between manually designed dark mode and AI-assisted light mode

## AI-Assisted Development Evidence

AI-assisted development evidence is shown through:

- A prompt log covering UI, frontend features, backend, Azure SQL, testing, CI, and documentation
- Agent instructions describing how AI should assist
- Context and configuration notes used to guide AI responses
