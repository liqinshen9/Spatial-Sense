# Planning and Design Evidence

This file records how the project was planned and designed before and during development.

## Initial Project Plan

At the beginning of the project, I planned to build a full-stack web application with three main parts:

- Frontend
- Backend
- Database

The frontend was planned as the part users interact with directly. It needed to include the homepage, gamepage, leaderboard page, tutorial animation, login/sign-up model, and game completion model. 

The backend was planned to handle the game logic, user accounts, authentication, score saving, and leaderboard data.

The database was planned to store user details, scores, difficulty levels, and leaderboard records so user progress and results could persist.

## Planned Features

### Login

Login was planned so each user could have their own identity. This also allowed scores to be connected to a specific user account.

### Leaderboard

The leaderboard was planned to make the game more competitive. It gives users a reason to improve their score and compare their performance with others.

### Tutorial

The tutorial was planned to help new users understand how to play before starting the main game. This was important because the game involves 3D spatial reasoning and rotation controls, which may not be obvious at first.

### Game Page

The game page was planned as the core experience of the project. This is where users complete the spatial reasoning challenge by rotating and matching 3D block structures.

### Homepage

The homepage was planned to be visually attractive because it is the first page users see. I wanted it to make the project feel polished and encourage users to start playing.

## UI Design Planning

The UI needed to support both dark mode and light mode.

Dark mode was designed manually without AI assistance. I used my own design choices for the dark version of the interface.

Light mode was designed with AI assistance. I used AI to help explore a cleaner and brighter visual direction while keeping the app suitable for a game.

## Design Considerations

Important design considerations included:

- Making the homepage visually engaging
- Keeping the game page clear and usable
- Making the leaderboard easy to scan
- Making the tutorial helpful without blocking the user too much
- Supporting both desktop and mobile screens
- Keeping feedback clear through loading states, messages, and sound effects
